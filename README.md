## 使用提示

- 模板中的姓名、联系方式、学校、公司和项目内容均为占位示例，请完整替换后再使用。
- 推荐使用 Microsoft Word 编辑；使用 WPS Office、LibreOffice 等软件时，排版可能略有差异。
- 增删内容后请检查分页、对齐和行距，避免导出 PDF 时出现内容溢出。
